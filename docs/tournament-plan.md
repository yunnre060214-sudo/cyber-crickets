# 比赛赛程实施计划

**目标：**八名 Agent 的六种分轮赛制、侧边创建入口和可恢复的赛程报告。

**结构：**复用纯规则 `Match` 跑双人对阵；`Tournament` 仅负责赛制与统计；侧边抽屉负责表单、推进和呈现。无新依赖，仍为静态站点。

**规格：**[tournament-design.md](./tournament-design.md)。

1. **双人对阵基础。**先增加失败测试，要求左右出生位置、换边后地图一致、参赛者随机流独立于座位；修改 `match.js` 并运行 `npm test`。
2. **赛制引擎。**先测试圆圈法七轮 28 对、双循环 56 对、淘汰晋级、小组与混合阶段、瑞士轮避重赛、积分同分顺序和相同种子重现；实现 `tournament.js`，再运行全套测试。
3. **页面与持久化。**先测试创建、分轮推进、恢复与报告输出；加入 `tournament-ui.js`、抽屉 HTML/CSS，保持单局入口正常；更新 README，运行全套测试和本地 HTTP 加载检查。

**审查重点：**双人局不能继承四角位置；回合推进不能重复计分；淘汰晋级不能错位；刷新恢复不能重跑已完成轮次；用户输入须作为文本呈现。
