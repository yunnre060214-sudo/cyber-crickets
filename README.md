# Cyber Crickets 2.0

一个无需账号、无需后端的算法竞技平台。使用原生 JavaScript、Web Worker、Canvas/SVG 和 IndexedDB；开发工具不进入运行产物。

**在线使用：https://yunnre060214-sudo.github.io/cyber-crickets/**

## 五个工作区

- **竞技场**：1v1 / 四方、三种模式、四种对称地图、21 种策略。改设置只影响下一局，开始新局时应用。每 5 模拟秒自动保存，可暂停、分享种子、继续存档。
- **赛事中心**：单循环、双循环、淘汰、小组、瑞士、小组＋淘汰。循环 / 淘汰 / 瑞士支持 4、8、16 人，小组相关支持 8、16 人；每对阵 1、3、5 张地图，每图换边两局，保存逐局回放。
- **回放分析**：逐 tick 重建棋盘与比分，跳转事件与领先易手，查看面积 / 资源 VP、资源保有及反抢，导出离线 HTML、Markdown 和完整 JSON.gz。
- **策略实验室**：选择种子、地图、时长、阵容和工作预算，完整轮换 / 换边后再聚合。可暂停、保存、继续，查看真实样本统计和本地单挑 Elo。
- **算法图鉴**：明确算法实际做法、版本与公开输入。BFS/DFS 风格、Monte Carlo 采样、防反和资源链是启发式，不冒充对应的完整搜索算法。

## 规则与可复现性

标准控制和资源迁移使用 20 ms 整数 tick、100 ms 同步决策。各方根据同一公开快照选择，最后统一解决冲突；到达终局不增加决策机会。地图、事件、策略、攻击与冲突随机流分别派生，播放速度和机器耗时不进入结算。

VP 按模拟时间积分：`6.5 × 领地 / 可通行格数 + 3.5 × 控制资源价值 / 总资源价值`。blocked 不进入面积分母。即时 reward 只用于策略反馈，独立于 VP。实时“当前胜率”是未校准的局势估计；实验室胜率来自实际样本：先对同一种子、地图、时长和阵容的轮换单局胜负取平均，再在该种子各配置间及独立种子之间平均；同分第一按人数分摊。该指标不同于换边双局累计 VP 的胜负，后者用于本地单挑 Elo。95% 区间按独立地图种子做 2000 次 bootstrap，少于 8 个种子只显示描述统计。Elo 仅使用完整单挑换边双局，初值 1000、K=24，按固定任务顺序更新。

三种模式：

- 标准控制：开局 24×1 + 8×3 资源价值合计 48；33% 新增 12×1，62% 新增 12×3，合计依次 60 / 96；82% 全体成功率增加 7.5 个百分点。
- 资源迁移：同样的永久资源，另有 8×3 临时资源；25% / 50% / 75% 轮换，临时节点消失后不继续产出。总资源价值保持 72；未来轮换计划公开。
- 经典 1.0：冻结 `eff46735` 引擎和 18 策略，保留原 .035 步进和原事件。旧 `agents/duration/rotation` 链接自动选经典模式；旧赛事继续经典规则。

平原、盆地、峡谷、环形均为 64×64，对称、连通，核心 3×3 受保护。统一工作预算为 4096 / 8192 / 16384，一次候选评分或路径展开计 1，虚拟行动计 4。耗尽后使用已评估最佳合法行动，未评分时选择首合法目标。

新增策略为实际 **A\*** 四邻路径规划、**边界调度器**和 **UCB1** 四宏观臂。保留最强 VP 规划器及十八种经典策略；名称不代表样本外强度保证。

时长 10～1800 秒整数，快捷 60 / 90 / 120 / 180；倍速 0.25×～20×，步进 0.25。四方曲线初始上限 `2.5 × 秒数`（120 秒为 300 VP），单挑为 `5 × 秒数`；超出后向上扩展，局内不回缩、不裁剪。

## 数据、导入与发布

IndexedDB 本地保存记录、1024 条账本块、检查点与唯一任务结果。版本冲突不会覆盖另一标签页的写入，重复任务不会再次计分。旧赛事 key 保留；旧 JSON v2 缺少完整随机状态，只能作为真实档案读取。

完整数据为版本 3。导入限制压缩 32 MiB，普通或展开数据 128 MiB；先校验版本、棋盘、身份、数值、账本与摘要，再事务保存。存储失败会报告未保存；请导出重要记录后再清理浏览器数据。本地记录不会自动同步到其他设备。

构建只发布 `dist/`。整个运行依赖图在同一个 `assets/<sourceHash>/` 目录，包含全部 Worker 和经典兼容模块；`build-info.json` 记录版本、commit SHA、构建摘要和逐文件 SHA-256。升级分支 / PR 先测试，main 通过检查后部署到 Pages。

```sh
npm ci
npm test
npm run build
npm run verify:dist
npm run test:browser
npm run acceptance
```

设计与实施计划位于 `docs/superpowers/`；发布验收和真实评测位于 `docs/benchmarks/`，发布说明位于 `docs/releases/`。
