# 赛博斗蛐蛐 · Cyber Crickets

一个浏览器端算法抢色块对战原型。四个算法阵营在同一张网格地图上自动扩张、抢资源和翻色，玩家只负责赛前选择算法并观战。

## 当前玩法

- 单局支持 60 / 90 / 120 秒，默认 90 秒。
- 四个阵营同时运行，拥有相同基础算力预算。
- 内置 BFS、DFS、A*、Greedy、Random 五种策略。
- 地图包含不同地形阻力、普通资源节点和高价值资源节点。
- 33%、62%、82% 进度分别触发资源潮汐、核心节点和终局超频事件。
- 核心区无法被占领，避免某一算法过早彻底出局。
- 胜负由持续占地积分、资源控制、翻色收益共同决定。
- 支持 1× / 2× / 4× 模拟速度。
- 响应式布局，可直接在桌面浏览器和手机浏览器运行。

## 运行

这是纯静态网页，无需构建工具。

```bash
python3 -m http.server 8080
```

然后打开：

```text
http://localhost:8080
```

也可以直接部署到 GitHub Pages、Cloudflare Pages、Netlify 或任意静态站点托管服务。

## 文件

- `index.html`：页面结构。
- `styles.css`：界面与响应式布局。
- `app.js`：模拟器、算法策略、计分与渲染。

## 后续适合扩展

1. 算法参数编辑器，例如攻击性、资源权重、目标搜索半径和算力预算。
2. 地图模板与随机种子。
3. BO3 / BO5 自动锦标赛。
4. 赛后时间线、领地曲线和逐帧回放。
5. Web Worker，将算法计算从 UI 主线程分离。
6. 自定义算法接口，让玩家提交自己的策略函数参赛。
