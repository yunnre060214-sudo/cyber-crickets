# 赛博斗蛐蛐 · Cyber Crickets

> 让不同算法在同一张地图上自己抢地、抢资源、翻色和博弈。玩家负责选阵容，然后看算法打架。

**在线试玩：** https://yunnre060214-sudo.github.io/cyber-crickets/

## 项目简介

Cyber Crickets 是一个纯浏览器运行的算法对战可视化项目。四个阵营会从地图四角出发，在统一规则下独立决策，通过扩张领地、争夺资源、进攻敌方色块和控制关键区域获得积分。

这个项目的重点不是“给不同颜色套几个数值”，而是让不同算法表现出**肉眼可见的行为差异**。有的算法会铺开战线，有的会穿刺深入，有的会主动避战，有的会围绕资源建网，还有的会在多局之间学习。

默认单局约 **90 秒**，适合快速观战和反复更换阵容。

## 当前特性

- 四阵营同时自动对战，玩家无需在局内手操。
- 支持 60 / 90 / 120 秒赛局，默认 90 秒。
- 支持 1× / 2× / 4× 模拟速度。
- 地图包含不同地形阻力、普通资源节点和高价值资源节点。
- 敌方色块可以被翻色，局势会持续发生变化。
- 核心区不可被彻底清除，避免过早淘汰导致垃圾时间。
- 赛局中会触发资源潮汐、中央高价值区和终局超频等阶段事件。
- 实时显示积分、领地占比、资源数量、翻色次数和决策耗时。
- 可显示算法当前“正在想什么”以及决策落点。
- ACO 信息素会直接可视化在地图上。
- Q-Learning 的 Q 表会保存到浏览器 `localStorage`，支持跨局保留经验。
- 桌面端、平板和手机均可直接运行。

## 算法阵容

当前内置 **12 种 Agent**：

| 算法 | 类型 | 主要表现 |
| --- | --- | --- |
| BFS | 反应型 | 均匀推进，优先维持连续战线 |
| DFS | 快攻型 | 沿既有方向持续深入，擅长穿刺 |
| Greedy | 反应型 | 只看当前收益，资源和翻色优先 |
| Random | 基准型 | 完全随机，用作基准线 |
| ACO 蚁群 | 群体型 | 信息素沉积与蒸发，逐渐形成“蚁道” |
| Voronoi | 稳健型 | 优先吃满自身势力圈，边界更整齐 |
| Potential Field | 反应型 | 资源产生引力，强敌产生斥力 |
| PID | 稳健型 | 根据目标面积和当前面积误差调节扩张力度 |
| Q-Learning | 学习型 | 在扩张、进攻、抢资源、巩固之间在线学习 |
| Minimax | 深谋型 | 评估最坏反击，偏向堵路和防夹击 |
| MCTS | 深谋型 | 在毫秒级预算内进行随机 rollout |
| MST | 结构型 | 用低成本路径连接资源点，形成枝状网络 |

所有算法统一通过可插拔接口运行：

```js
selectAction(view) => action
```

因此新增算法时不需要改动整个战场引擎，只需要实现新的 Agent。

## 对局机制

胜负并非单纯比较最终领地面积。积分主要来自持续占地、资源控制和成功翻色，因此不同算法可以通过不同方式赢下比赛。

地图会随着赛局进度发生阶段变化：

- **前期**：快速扩张，建立基本版图。
- **中期**：边界接触，资源争夺和翻色增加。
- **后期**：中央高价值区域开放，算法开始集中博弈。
- **终局**：翻色效率提升，扩大最后反转空间。

## 观战可视化

为了让比赛不只是“看颜色扩散”，界面会额外展示算法内部决策信息：

- 当前排名与总积分。
- 领地占比、资源、翻色次数。
- 单次决策耗时。
- 当前策略意图。
- 决策目标格。
- ACO 信息素热区。

重算法会以更低决策频率换取更复杂的决策过程，使“算得更久”和“行动更快”之间存在真实取舍。

## 技术实现

项目目前是纯静态前端，不依赖后端服务，也不需要构建工具。

```text
index.html      页面结构
styles.css      UI 与响应式布局
app.js          战场模拟、计分、渲染与对局流程
agents.js       所有可插拔算法 Agent
.github/
  workflows/
    deploy-pages.yml   GitHub Pages 自动部署
```

每次提交到 `main` 后，GitHub Actions 会自动部署最新版本到 GitHub Pages。

## 本地运行

直接使用任意静态服务器即可，例如：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 后续方向

当前版本已经具备完整的“选算法 → 自动对战 → 观战 → 结算”循环。后续比较适合继续扩展：

1. 算法参数编辑器，例如攻击性、资源权重、搜索深度和算力预算。
2. 地图模板、地图种子和特殊地形。
3. BO3 / BO5、自动联赛和算法胜率统计。
4. 赛后领地曲线、时间线和逐帧回放。
5. Web Worker，将 MCTS、GA 等重算法移出 UI 主线程。
6. 自定义 Agent 接口，让其他人直接提交自己的算法参赛。
7. GA、UCB、Thompson Sampling、Boids、模拟退火等更多策略。
8. 长期排行榜与算法版本对比。
